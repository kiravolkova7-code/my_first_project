# Проект My first project
## Описание: 
Проект My first project - это приложение для банковских операций клиента.

## Функционал: 
На данном этапе приложение имеет ряд функций:
* Маскирует номер банковской карты
* Маскирует номер банковского счета
* Принимает строку вида 'Visa Platinum 7000792289606361' или 'Счет 73654108430135874305'
    и возвращает строку с замаскированным номером.
* Преобразует строку с датой из формата "2024-03-11T02:26:18.671407"
    в формат "ДД.ММ.ГГГГ" (например, "11.03.2024").
* Фильтрует список словарей по значению ключа 'state'.
* Сортирует список словарей по ключу 'date' (в формате ISO 8601).
* Генератор, который возвращает итератор, который поочередно выдает 
   транзакции, где валюта операции соответствует заданной (например, USD).
* Генератор, который принимает список словарей с транзакциями и 
возвращает описание каждой операции по очереди.
* Генератор, который выдает номера банковских карт в формате 
XXXX XXXX XXXX XXXX, где X — цифра номера карты. 
* Декоратор, который будет автоматически логировать начало и конец выполнения функции, 
а также ее результаты или возникшие ошибки.
* Принимает на вход путь до JSON-файла и возвращает список словарей с данными о финансовых транзакциях.
* Принимает на вход транзакцию и возвращает сумму транзакции в рублях.

## Установка:
Клонируйте приложение из GitHub: 

```
git clone https://github.com/kiravolkova7-code/my_first_project.git
```
Для корректной работы в файл `.env` необходимо разместить Ваш API-key. В репозитории есть 
файл `.env.example` для примера.

## Тестирование:
Проект покрыт модульными тестами, написанными с использованием фреймворка pytest. 
Тесты гарантируют корректную работу ключевых функций и устойчивость к некорректным входным данным.

Тесты охватывают следующие модули и сценарии:

###  Функции: get_mask_card_number, get_mask_account

Что проверяется:
* Корректное маскирование номеров карт и счетов.
* Обработка строк с пробелами и ведущими нулями.
* Валидация длины входных данных (генерация исключения ValueError 
для слишком коротких или длинных номеров).
* Обработка пустых строк и некорректных символов.
### Функции: filter_by_state, sort_by_date.
Что проверяется:
* Фильтрация списков объектов по статусу (state), включая 
обработку значения None и неизвестных статусов.
* Сортировка списков по полю даты (date) в порядке возрастания и убывания.
* Сохранение исходного порядка элементов при наличии одинаковых дат.
* Устойчивость к невалидным форматам дат (функция не должна падать).
### Функции: mask_account_card, get_date.
Что проверяется:
* mask_account_card: Умное маскирование в зависимости от типа данных (карта или счет), а также обработка множества некорректных форматов ввода.
* get_date: Корректное преобразование даты из формата ISO в формат ДД.ММ.ГГГГ, включая проверку високосных лет и граничных значений.
### Функция filter_by_currency
Что проверяется:
* Функция корректно фильтрует транзакции по заданной валюте.
* Функция правильно обрабатывает случаи, когда транзакции в заданной 
валюте отсутствуют.
* Генератор не завершается ошибкой при обработке пустого списка или 
списка без соответствующих валютных операций.
### Функция transaction_descriptions
Что проверяется:
* Функция возвращает корректные описания для каждой транзакции.
* Тестирование с различным количеством входных транзакций, 
включая пустой список.
### Функция card_number_generator
Что проверяется:
* Генератор выдает правильные номера карт в заданном диапазоне.
* Корректность форматирования номеров карт.
* Генератор корректно обрабатывает крайние значения диапазона и 
правильно завершает генерацию.
### Функция-декоратор log
Что проверяется: 
* Проверяет, что при успешном выполнении функции с логированием в консоль вывод содержит ok и имя функции. 
* Проверяет запись успешного выполнения в файл. 
* Проверяет, что при возникновении ошибки выводится информация о типе ошибки и входных данных.
* Проверяет корректное логирование именованных аргументов (**kwargs) при возникновении ошибки.
### Фунуция load_operations
Что проверяется:
* Проверяет, что функция корректно загружает валидный JSON-список.
* Проверяет, что функция возвращает пустой список, если файл не найден. 
* Проверяет обработку некорректного JSON-контента.
### Функции convert_to_rub и get_transaction_amount_in_rub
Что проверяется:
* Если валюта уже RUB, сумма должна возвращаться без изменений.
* Тест успешной конвертации USD в RUB.
* Тест ошибки, если API-ключ не найден.
* Тест обработки HTTP-ошибки (например, 401 Unauthorized).
* Тест успешной обработки транзакции в USD.
* Если в транзакции нет поля 'currency', должно использоваться значение по умолчанию ('RUB').
* Тест ошибки, если сумма транзакции не является числом.



### Запуск тестов
Для выполнения тестов необходимо иметь установленный pytest. 
Запустить все тесты в проекте можно из корневой директории следующей командой:
```
pytest
```
