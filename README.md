# Проект My first project
## Описание: 
Проект My first project - это приложение для банковских операций клиента.

## Функционал: 
На данном этапе приложение имеет ряд функций:
* Маскирует номер банковской карты
* Маскирует номер банковского счета
* Принимает строку вида 'Visa Platinum 7000792289606361' или 'Счет 73654108430135874305'
    и возвращает строку с замаскированным номером.
* Преобразует строку с датой из формата "2024-03-11T02:26:18.671407"
    в формат "ДД.ММ.ГГГГ" (например, "11.03.2024").
* Фильтрует список словарей по значению ключа 'state'.
* Сортирует список словарей по ключу 'date' (в формате ISO 8601).

## Тестирование:
Проект покрыт модульными тестами, написанными с использованием фреймворка pytest. 
Тесты гарантируют корректную работу ключевых функций и устойчивость к некорректным входным данным.

Тесты охватывают следующие модули и сценарии:

* ###  Функции: get_mask_card_number, get_mask_account

Что проверяется:
* Корректное маскирование номеров карт и счетов.
* Обработка строк с пробелами и ведущими нулями.
* Валидация длины входных данных (генерация исключения ValueError 
для слишком коротких или длинных номеров).
* Обработка пустых строк и некорректных символов.
* ### Функции: filter_by_state, sort_by_date.
Что проверяется:
* Фильтрация списков объектов по статусу (state), включая 
обработку значения None и неизвестных статусов.
* Сортировка списков по полю даты (date) в порядке возрастания и убывания.
* Сохранение исходного порядка элементов при наличии одинаковых дат.
* Устойчивость к невалидным форматам дат (функция не должна падать).
* ### Функции: mask_account_card, get_date.
Что проверяется:
* mask_account_card: Умное маскирование в зависимости от типа данных (карта или счет), а также обработка множества некорректных форматов ввода.
* get_date: Корректное преобразование даты из формата ISO в формат ДД.ММ.ГГГГ, включая проверку високосных лет и граничных значений.

### Запуск тестов
Для выполнения тестов необходимо иметь установленный pytest. 
Запустить все тесты в проекте можно из корневой директории следующей командой:
```
pytest
```
